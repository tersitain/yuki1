# 2年生 かんじ・九九クイズ

小学2年生向けの学習クイズ（家庭用）。ログイン不要で、記録は端末の中だけに保存されます。

- かんじ：2年生で習う160字 ×「よみ」「かき」＝320問
- 九九：1〜9の段、81問
- 19×19：11〜19の段、162問（ヒントの図と、10と残りに分ける手順の説明つき）
- □の計算：□に入る数をもとめる問題、5種類72問（ヒントと、式を逆にたどる解き方の説明つき）
- むずかしさは「おうちの方へ」で切りかえ（むずかしい＝4択・計算は数字入力・ボスは時間制限つき）

## 直し方

問題は `src/kanji.txt`、画面は `src/template.html` にあります。直したあと `python3 src/build.py` を実行すると、`index.html` と `sw.js` が作り直されます。
