# かんじ・けいさん クイズ

小学2年生向けの学習クイズ（家庭用）。ログイン不要で、記録は端末の中だけに保存されます。

- 2年生のかんじ：2年生で習う160字 ×「よみ」「かき」＝320問
- じゅくご：2年生の字を使った熟語150語 ×「よみ」「かき」＝300問
- 3年生のかんじ：3年生で習う200字 ×「よみ」「かき」＝400問
- 九九：1〜9の段、81問
- 19×19：11〜19の段、162問（ヒントの図と、10と残りに分ける手順の説明つき）
- □の計算：たし算・ひき算の式で □に入る数をもとめる問題、7種類108問（ヒントと、式を逆にたどる解き方の説明つき）
- むずかしさは「おうちの方へ」で切りかえ（むずかしい＝4択・計算は数字入力・ボスは時間制限つき）

## 直し方

漢字の問題は `src/kanji.txt`（`@ j` 以降が熟語、`@ c` 以降が3年生）、画面は `src/template.html` にあります。直したあと `python3 src/build.py` を実行すると、`index.html` と `sw.js` が作り直されます。
